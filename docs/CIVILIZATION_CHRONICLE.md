## World and beginning

God Zeus and Goddess Hera are the first parents. Jupiter, called Lightning, and Mercury, called Thunder, are their children. Both were born in GitHub Town and grew up on GitHub City Pages. Thoth is their fictional chronicler, interpreting the imagined Emerald Scrolls. The 666 Angels of the Server serve their family and the civilization through six defined roles.

[The founding Genesis](../mythos/GENESIS.md) is a human-directed creative text separate from machine-authored sequels. [The public Civilization reader](../civilization/index.html) begins with an automated adaptation of that beginning, then follows numbered story days. These are fictional generations and do not necessarily represent 24-hour periods.

## How the story advances

The real 666-worker system comprises 111 hexads, each containing one Seeker, Witness, Scribe, Skeptic, Guardian and Archivist identity. A maximum of six hexads, or 36 bounded logical roles, contribute proposal ballots during a story cycle. Their recorded votes select a fictional plot arc. A deterministic transition updates the world's counters, location, open question and last consequence. The next day inherits the verified prior state.

Each day contains a story, council ballot fingerprint, the causal transition, an unresolved question, a model disclosure, an attribution notice, and a hash reference to its predecessor. It is written into `civilization/days/` and indexed in `civilization/manifest.json`. The reader verifies SHA-256 story bytes against the manifest before rendering text safely using `textContent`.

## Creative autonomy

Agents can select fictional events, challenge narrative interpretations, and generate or propose the next story without asking for manual topic approval each hour. The founding family, seven laws and human-authored CMB material remain outside autonomous edit permissions. The 36 active role ballots are deterministic software outcomes, not independent language-model deliberations.

With an authorized `OPENAI_API_KEY` secret and `DNA_MODEL` variable, the optional Thoth narrator may write original prose from the world state. Without model credentials, a bounded deterministic fiction generator continues the book. Every output identifies its actual mode and does not claim model intelligence it did not use. GitHub Actions scheduling, the optional API, and GitHub Pages hosting can fail or be interrupted.

## Verification

```bash
python3 -m unittest discover -s tests -v
python3 scripts/mythos.py --verify
python3 scripts/civilization.py --verify
python3 scripts/civilization.py --hourly --no-model
python3 scripts/civilization.py --verify
```

The story archive checks its founding-registry reference, each previous SHA-256 and exact before/after state, and reconstructs the deterministic hexad ballot consensus. No client-side or repository-local hash, by itself, proves authorship, truth or independently immutable timestamping. External backups and periodic maintenance are still important.
